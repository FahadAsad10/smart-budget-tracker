# Smart Budget Tracker

A client-side personal budgeting website built with React, TypeScript, Vite, Recharts and Lucide React.

## Features
- Monthly income and expense tracking
- Search and category filtering
- Transaction history with delete controls
- Category budgets with 80%+ alerts
- Savings goals and progress tracking
- Spending trend and category analytics
- Rule-based Smart Budget Coach — no AI key or server required
- Responsive desktop/mobile dashboard
- Local browser-only session data

## Privacy
This project does not require accounts or a database. Budget data is kept in the browser session and is not uploaded to a cloud database. Closing the browser session may clear the data.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Tech stack
React 19 · TypeScript · Vite · Recharts · Lucide React

Built as a long-running personal development project focused on turning a simple budgeting concept into a polished, usable frontend product.
